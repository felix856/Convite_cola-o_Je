💌 Um convite para a Je

Um projeto pequenininho, feito com carinho, HTML e um pouquinho de coragem. ✨

Sabe quando você quer chamar alguém especial pra sair, mas uma mensagem comum parece pouco? Então. Este repositório nasceu disso: uma página que é um convite, um date e uma surpresinha escondida, tudo num arquivo só.

Tudo aconteceu no dia da colação de Análise e Desenvolvimento de Sistemas 🎓. Nada mais justo do que usar o que eu aprendi para fazer algo que realmente importa.

🌅 O que tem aqui
Um céu de fim de tarde com o sol se pondo, porque a gente se vê às 18h30.
Uma linha do tempo do dia: a colação às 17h e você às 18h30.
Um pedido de date no estilo "você escolhe, eu busco, o resto deixa comigo". ❤️
Escolhas dela: o dia, o que comer (ou fazer, tipo café ☕ ou piquenique 🧺) e o lugar que ela gostaria de ir.
Onde buscar, porque cavalheiro busca. 🚗
Um botão "Pensando bem..." que foge 😂. Spoiler: ele não é uma opção.
Chuva de corações quando ela confirma. 💕
Mensagem automática no WhatsApp com tudo que ela escolheu.
Um easter egg 👀. Não vou contar onde. Procura aí.
🧁 Como usar

É só abrir o index_Je.html no navegador. Não precisa instalar nada, não tem dependência, não tem build. Só amor e um arquivo HTML. 🫶

Trocar o número do WhatsApp

Procure esta linha no final do arquivo:

js
const meuWhatsApp = '5548991236653';

E coloque o seu número no formato 55 + DDD + número, sem espaços nem símbolos.

Colocar no ar 🌐

Quer mandar como link? Dá pra publicar de graça no GitHub Pages:

Crie um repositório e suba o arquivo renomeado para index.html.
Vá em Settings → Pages.
Escolha a branch main e salve.
Em alguns minutos o link estará pronto pra ser enviado. 💌
